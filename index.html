Всё можно вернуть

VELOCITY записывает состояние перед каждым изменением, Updater пишет файл отката, HwRename хранит оригинальные названия, Threat Scanner кладёт находки в карантин вместо удаления.

Без плацебо

Никаких «+300% FPS». Если эффект спорный, так и написано. Updater прямо говорит, что пароли Chrome не переносятся, вместо того чтобы ломать их защиту.

Проверка на чистой системе

Updater прогоняется в Windows Sandbox на свежей Windows 11, у Jarvis 454 автотеста, сканер проверяется на ложные срабатывания, у роликов проверяется микс.

Выпуск по тегу

Ставлю тег в git, GitHub Actions собирает программу, гоняет тесты и выкладывает exe с контрольной суммой SHA-256. Updater и FI обновляются сами.

Свой стиль

Оформление переходит между проектами: темы FI легли в VELOCITY, тема «Графит» из VELOCITY в Updater. Каждый сериал Shorts получает свой шрифт, титры и звук.

В паре с ИИ

Идея, требования и решения мои. Код пишут ИИ-агенты Claude Code и Codex, а я проверяю результат, тестирую на своём ПК и веду проект дальше.

Как считалось. Строки кода: непустые строки в исходниках (Python, C#, XAML, Go, C++, TypeScript, JS, HTML, CSS, скрипты) без node_modules, виртуальных окружений, сборок и сгенерированных файлов. Коммиты и выпуски: история git и теги на GitHub.
Часы — активное время в сессиях Claude Code: паузы дольше 15 минут не считаются, параллельные чаты по одному проекту не складываются. Чаты до 6 октября потерялись при переустановке Windows, а работа в Codex сюда не попала, поэтому для Mailer-Bot, Marketplace Parser, ранних версий FI, VELOCITY и Threat Scanner реальных часов больше.
Снимки. В окнах Threat Scanner и Luxery показаны демо-данные, в остальных настоящие.
