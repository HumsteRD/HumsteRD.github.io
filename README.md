# Портфолио HumsteRD

Сайт: **https://humsterd.github.io**

Программы для Windows, боты и вертикальные ролики из кода: интерфейсы, фишки, видео и хронология работы.

Страница собирается из одного исходника скриптом, в этом репозитории лежит готовый результат: `index.html` и папка `media` со снимками и роликами.
